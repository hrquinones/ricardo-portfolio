# SEO Specification

## Objective

Make the portfolio discoverable for professional searches related to Ricardo's actual expertise and experience.

## Primary topic areas

- Senior Backend Engineer
- Backend Engineering
- Tech Lead
- Node.js
- Software Architecture
- Microservices
- Legacy Modernization
- Cloud / AWS
- Payments
- React Native / Mobile integration

Do not create pages or claims solely to target keywords if they are not supported by the professional content.

## Metadata

Every indexable page:

- unique title;
- useful description;
- canonical URL;
- Open Graph metadata.

## URL conventions

Lowercase kebab-case.

Examples:

- `/work/card-onboarding`
- `/work/nfc-payments`
- `/experience`
- `/about`

## Sitemap

Include all public canonical pages.

## Robots

Production should be indexable.

Preview environments should not be indexed.

## Structured data

Initial:

- Person
- WebSite

Use only truthful information.

## Open Graph

Use a consistent visual identity.

Case-study pages should ideally have contextual OG titles/images.

## Internal linking

Home → Work → Case Study.
Case studies → related work.
Experience → related case studies.
About / CV / Contact should remain easy to reach.

## SEO quality checks

- No duplicate titles.
- No missing descriptions on key pages.
- Correct heading hierarchy.
- Descriptive link text.
- Canonical URLs.
- Sitemap available.
- Robots available.
- No accidental `noindex` in production.
